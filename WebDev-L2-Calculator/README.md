
# 🧮 Calculator — OASIS INFOBYTE Internship

## 📌 Project Overview

This project is a fully functional, responsive calculator developed as part of my **OASIS INFOBYTE Web Development & Designing Internship**.

**Level:** 2  
**Task:** 1 — Calculator  
**Developer:** Darryl Mokwele

The calculator performs basic arithmetic operations with a modern user interface. It supports keyboard input, operator chaining, decimal calculations, and error handling.

## 🚀 How to Run the Project

### Option 1: Open in Browser

1. Download or clone the repository.
2. Navigate to `WebDev-L2-Calculator`.
3. Double-click `index.html`.
4. Start using the calculator.

### Option 2: Run Using VS Code

1. Open the project in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. The calculator opens in your browser.

No additional dependencies are required.
